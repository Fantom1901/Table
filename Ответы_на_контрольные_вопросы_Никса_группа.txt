1. Какой тег является тегом-контейнером таблицы?
Ответ: Тег <table>.

2. Чем отличаются теги <th> и <td>?
Ответ: Тег <th> (table header) используется для создания заглавных ячеек, текст в них по умолчанию жирный и выровнен по центру. Тег <td> (table data) предназначен для стандартных ячеек с данными.

3. Как добавить название таблицы?
Ответ: Название добавляется с помощью парного тега <caption>, помещаемого сразу после открывающего тега <table>.

4. Какими атрибутами обладает тег <table>?
Ответ: Атрибуты включают border (толщина рамки), width (ширина), align (выравнивание таблицы), bgcolor (цвет фона), bordercolor (цвет рамки), cellspacing (расстояние между ячейками), cellpadding (расстояние внутри ячеек).

5. Как объединить ячейки одного столбца или строки?
Ответ: С помощью атрибута rowspan (объединение строк/по вертикали) и colspan (объединение столбцов/по горизонтали).

6. Как выровнять содержимое ячеек в HTML-документе?
Ответ: С помощью атрибута align (left, center, right) для горизонтального выравнивания и valign (top, middle, bottom) для вертикального.
